# Frontend

## Quickstart Setup

### 1. Install dependencies

```shell
npm install
```

### 2. Run

```shell
npm run dev
```

### 3. Navigate to [http://localhost:5173/](http://localhost:5173/).

## Overview

This frontend is intended to serve as an example interface for interacting with the RAG.

### Pages

- Chat: [http://localhost:5173/](http://localhost:5173/)
- Document Store: [http://localhost:5173/files](http://localhost:5173/files)
- Evaluation: [http://localhost:5173/evaluation](http://localhost:5173/evaluation)
